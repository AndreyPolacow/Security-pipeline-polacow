# Демонстрационные результаты запуска pipeline

| Проверка | Ожидаемый результат | Назначение |
|---|---|---|
| pip-audit | Устаревшие Python-зависимости | SCA: поиск CVE в зависимостях |
| Bandit | `shell=True` и пользовательский ввод | SAST: небезопасный вызов командной оболочки |
| Semgrep | `DEMO_TOKEN` | Учебное обнаружение псевдосекрета |
| zizmor | Предупреждения по workflow | Аудит безопасности GitHub Actions |
| Trivy | Замечания по Dockerfile/зависимостям | Container/IaC scanning |

Все finding являются учебными и созданы для проверки воспроизводимости security pipeline.
